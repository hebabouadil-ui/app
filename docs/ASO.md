## 7. iOS Keywords Field (100 characters, comma-separated, no spaces)

> Apple indexes the App Name, Subtitle, and this Keywords field. **Do not** repeat words already used in your name/subtitle (wasteful), avoid spaces after commas, and don't use plurals if you have the singular (Apple matches both). Avoid competitor brand names.

**Recommended keywords string (99 chars):**
```
aura,luck,horoscope,reading,palm,zodiac,selfie,camera,quiz,test,mood,destiny,fortune,vibe,glow,fun
```
**Char count:** 99 / 100

**Why these words:**
- **aura, vibe, glow** — reinforce the signature Aura Score feature; low competition, on-theme.
- **luck, fortune, destiny, horoscope, zodiac** — high-volume "prediction/astrology-adjacent" discovery terms (kept playful).
- **reading, palm** — capture "fortune reading / palm reading" curiosity searches (palm is a popular adjacent term even though the app scans faces).
- **selfie, camera** — capture the face-scan/photo intent.
- **quiz, test, fun** — signal entertainment and capture "personality test/quiz" searches.
- **mood** — supports Future Mood + Daily Mood prediction.

> **Note:** "face", "personality", "AI", "prediction", "scan", "celebrity" should appear in the **App Name + Subtitle** instead of the keyword field so you don't waste characters duplicating them. Apple automatically combines name + subtitle + keyword field into search permutations.

## 8. Google Play Keyword Strategy

Google Play has **no dedicated keyword field** — it indexes the **Title (30)**, **Short Description (80)**, and **Long Description (4000)**. Algorithm rewards relevance + density (but keyword stuffing is penalized and looks spammy to users).

**Placement rules:**
1. **Title:** Include your single strongest keyword cluster — `Face` + `Aura`. (e.g., `Dream AI: Face & Aura Fun`).
2. **Short Description:** Pack 3–4 primary keywords naturally — `face scan`, `Aura Score`, `daily luck`, `personality`.
3. **Long Description:** Aim for each **primary** keyword to appear **3–5 times**, **secondary** 1–2 times, woven into natural sentences and feature headers. Front-load the first 167 characters (the visible preview).
4. Use a keyword in a **header** (emoji line) AND in body copy — Play weights early/structural mentions.

### Prioritized Keyword Table

| Priority | Keyword / Phrase | Search Intent | Suggested Placement |
|----------|------------------|---------------|---------------------|
| **Primary** | face scan / face analyzer | Core feature discovery | Title, Short Desc, Long Desc ×4 |
| **Primary** | aura score / aura reading | Signature feature | Title, Short Desc, Long Desc ×4 |
| **Primary** | daily luck / luck prediction | High-volume fun term | Short Desc, Long Desc ×4 |
| **Primary** | personality test | Popular quiz intent | Short Desc, Long Desc ×3 |
| **Secondary** | mood prediction | Feature + theme | Long Desc ×2 |
| **Secondary** | face reader | Variant of core feature | Long Desc ×2 |
| **Secondary** | celebrity look-alike | Viral/share intent | Long Desc ×2 |
| **Secondary** | personality insights | Feature | Long Desc ×2 |
| **Secondary** | fortune / destiny | Adjacent discovery | Long Desc ×1–2 |
| **Long-tail** | what celebrity do I look like | Question search | Long Desc ×1 |
| **Long-tail** | fun face scanner app | Niche intent | Long Desc ×1 |
| **Long-tail** | daily positive message | Feel-good intent | Long Desc ×1 |
| **Long-tail** | friendship compatibility test | Social/share | Long Desc ×1 |
| **Long-tail** | first impression test | Feature | Long Desc ×1 |
| **Long-tail** | aura color reading for fun | Signature long-tail | Long Desc ×1 |

> **Compliance reminder:** Keep every keyword framed as entertainment. Avoid health/medical adjacent terms ("face analysis for health", "skin", "diagnosis", "symptom") — these risk policy rejection and contradict the entertainment positioning.
